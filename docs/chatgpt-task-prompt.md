# Former task format (superseded)

The single daily ChatGPT news digest has been split into two tasks:

- [Hourly brief task](chatgpt-hourly-task.md)
- [End-of-day highlights task](chatgpt-daily-task.md)

Legacy outbox/YYYY-MM-DD.json and published/YYYY-MM-DD.json files
remain as archives. The new publisher accepts only JSON files in
outbox/hourly/ or outbox/daily/.
